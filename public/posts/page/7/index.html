How to Fix the VC_FAULT_FATAL Error Whenever you see this particular error, this means that Horizon is trying to create a new VM but can’t because a VM with that name already exists. This can happen for many reasons but most commonly, the VC_FAULT_FATAL - The name already exists error occurs because Horizon can no longer communicate with the VM in vSphere.
